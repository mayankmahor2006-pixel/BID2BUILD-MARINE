# 🚤 BID2BUILD MARINE – TEAM CRUISERS

## 1. Project Overview

BID2BUILD MARINE is a technical boat-making project developed by TEAM CRUISERS for the BID2BUILD MARINE competition at AAROHAN 2026, organized by AICTE IDEA LAB, SGSITS, Indore.

The project is based on the Arduino Uno microcontroller, which acts as the main control unit of the boat. It demonstrates the practical application of embedded systems, electronics, programming, and electrical engineering concepts in marine technology.

- To design and develop a functional technical boat.

## 3. Components Used

The project uses Arduino Uno as its main microcontroller.

The complete component list will be documented according to the actual circuit diagram.

| S.No. |  Component

| 5 | 18650 Li-ion Batteries.
| 6 | SriTu Hobby Phone Application.


## 4. Working Principle

The Arduino Uno acts as the central controller of the boat. It executes the uploaded program and controls the connected electronic components according to the programmed instructions.

The electronic circuit provides the required connections between the controller, power supply, and other hardware components.

The complete working process, including motor control, power distribution, and any communication system, will be explained after verifying the circuit diagram.
